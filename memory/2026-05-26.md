### 18m. 锻件报价计算器：GitHub Gist 云同步功能完成

**背景**：用户创建了 Gist 用于跨设备记录同步，要求实现自动云同步。

**Gist 信息**：
- URL: https://gist.github.com/mohudeyingzi/e043c5a6fad1698b9c67508f3316ad16
- Raw URL: https://gist.githubusercontent.com/mohudeyingzi/e043c5a6fad1698b9c67508f3316ad16/raw/forging_sync_records.json
- CORS: `Access-Control-Allow-Origin: *` ✅

**已实现的功能**：

1. **自动拉取（页面打开时）**
   - 页面加载后自动 fetch Gist Raw URL 获取云端记录
   - 与本地记录合并（云端优先，本地去重）
   - 无需任何配置，打开页面即可自动同步

2. **手动云同步面板**（工具栏「☁️ 云同步」按钮）
   - Raw URL 输入框（预填你的 Gist 链接）
   - Token 输入框（选填，填写后支持推送）
   - 「⬇️ 立即拉取」手动触发同步
   - 「⬆️ 推送到云端」上传本地记录到 Gist（需 Token）
   - 「💾 保存设置」持久化配置

3. **自动上传（保存记录时）**
   - 如果配置了 GitHub Token，保存记录后自动推送到 Gist
   - 无需手动操作

4. **UI 状态**
   - 云同步按钮根据最后同步时间显示状态
   - 同步日志实时显示

**如何启用自动上传**：
1. 打开 https://github.com/settings/tokens → Generate new token (classic)
2. 只勾选 `gist` 权限
3. 复制 token → 粘贴到云同步面板的 Token 框 → 保存设置

**修改的代码**：
- HTML：工具栏新增云同步按钮和设置面板
- CSS：`.btn-sm-sync`、`.sync-panel` 等样式
- JS：`syncFromCloud()`、`syncToCloud()`、`autoSyncFromCloud()`、`saveSyncSettings()` 等函数
- 页面初始化：自动调用 `autoSyncFromCloud()`
- `saveRecord()`：自动触发 `syncToCloud()`（如配置了 Token）

**文件**：`forging-calculator-template.html`

**问题**：手机竖屏打开 `forging-calculator-template.html` 时部分内容看不见（主要是结果区被推出去）。

**根因**：
- `.result-wrap{margin-left:126px}` 结果区超大左偏移量
- `.r-row{grid-template-columns:150px 1fr 120px 90px}` 4列固定宽度，手机屏超限
- `.result-input{width:216px}` 结果输入框太宽
- 无 600px 以下手机专用断点（只有 900px 断点）

**修复**：新增 `@media(max-width:600px)` 手机竖屏专用断点，覆盖：
- 信息区 5→2 列，信息格单列 display
- 段区 `.seg-row` 改为 `column` 纵向堆叠，尺寸输入独立行
- 结果区 margin-left:0，`result-input` 宽→70px
- `.r-row` 改为 3 列（隐藏备注列），label:80px / 1fr / value:60px
- `.dim-input{width:55px}` `.dim-allow{width:42px}` 手机端尺寸适配
- 工具栏/历史记录工具栏全 wrap
- 云同步面板纵向堆叠
