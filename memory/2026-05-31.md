- 找到名为 "锻件计算器数据备份" 的私有 Gist

## 2026-05-31 17:21 - gist.github.com 国内无法访问问题

### 问题
用户反馈 https://gist.github.com 打不开

### 原因
`gist.github.com` 域名在中国大陆地区经常被封锁或不稳定

### 替代方案
1. **通过 GitHub 主站访问**（推荐）
   - 直接打开 https://github.com/settings/gists
   - 或：登录 GitHub → 右上角头像 → Your gists

2. **通过 API 查询**
   - 浏览器打开：`https://api.github.com/users/{username}/gists`
   - 返回 JSON 格式的 Gist 列表，包含 ID 和文件名

### 待开发功能
"找回 Gist" 按钮：
- 调用 `GET /gists` API（需要 Token）
- 列出用户所有包含 `forging_sync_records.json` 的 Gist
- 一键选择恢复，无需手动访问 gist.github.com
- 绕过国内访问限制，直接在应用内完成恢复

### 用户体验优化建议
考虑国内网络环境，云同步功能应尽量：
- 减少对外部站点（如 gist.github.com）的依赖
- 所有操作尽量在应用内完成
- API 调用走 github.com（相对稳定）而非 gist.github.com
