# Python 依赖库安装 - 2026-05-15

## 任务
安装 CAD/图像处理所需的 Python 依赖库

## 操作
1. 卸载 Python 3.14.2（旧版本）
2. 安装 Python 3.12.10（稳定版本）
3. 清理 PATH 环境变量，移除 Python 3.14 相关路径
