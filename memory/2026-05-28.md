## 锻件计算器删除重加后不显示结果修复 (14:03)

修复了 `forging-calculator-template.html` 中删除段落后重新添加，结果不自动显示的 bug。

**问题**：删除某段后重新添加并填入尺寸，后面的结果（尺寸和重量）不自动显示。

**根因**：`calcAll()` 用数组下标 `i+1` 作为写入目标的 DOM ID，而非段落的实际 DOM ID。当 `cylN` 只增不减时，删除后新加的段落 ID 与 `calcAll` 计算的写入位置不匹配。

**修复**（4处）：
1. `collectSeg()` 增加 `r.id=id` 返回段落真实 DOM ID
2. `calcAll()` cyl 循环：`var ti=i+1` → `var ti=c.id`
3. `calcAll()` rect 循环：`var ti=i+1` → `var ti=r.id`
4. `calcAll()` hole 循环：`var ti=i+1` → `var ti=h.id`

结果元素 ID 现在始终与段落 DOM ID 匹配。
